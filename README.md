# 🎣 Интерактивный путеводитель по Русской Рыбалке Installsoft Edition 3.7.6. - Руководство по установке

## 🔧 Шаг 1: Установка Python

1. Скачайте Python 3.10 с официального сайта:  
   👉 https://www.python.org/downloads/release/python-31020/
2. Запустите установщик
3. **ВАЖНО:** Поставьте галочку ✅ **«Add Python to PATH»**
4. Нажмите **«Install Now»**

---

## 🗄️ Шаг 2: Установка PostgreSQL

1. Скачайте PostgreSQL с официального сайта:  
   👉 https://www.postgresql.org/download/windows/
2. Запустите установщик
3. При установке:
   - Пароль для пользователя `postgres` - **запомните его**
   - Порт: `5432` (по умолчанию)
   - Остальное - по умолчанию
4. **Снимите галочку** с «Stack Builder» в конце установки

---

## 🗂️ Шаг 3: Распаковка

Распакуйте архив с приложением в удобное место (например: `C:\RF37IE\`)

---

## 🚀 Шаг 4: Запуск скриптов установки

### 4.1 Создание базы данных
Запустите двойным щелчком:  
📄 **`1. Создание базы данных.bat`**

### 4.2 Установка зависимостей и миграций
Запустите двойным щелчком:  
📄 **`2. Установка.bat`**

---

## 🎮 Шаг 5: Запуск приложения

Запустите двойным щелчком:  
📄 **`3. Запуск.bat`**

Скрипт:
- Запустит веб-сервер
- Автоматически откроет браузер

Приложение доступно по адресу:  
👉 **http://127.0.0.1:8000/**

Для остановки сервера - закройте окно командной строки или нажмите `Ctrl+C`

---

## 🔁 Повторный запуск

После первой установки для запуска приложения используйте только:  
📄 **`3. Запуск.bat`**

Скрипты `1` и `2` нужны только один раз при первоначальной установке.
